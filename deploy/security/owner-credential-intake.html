قبل أن تبدأ — اقرأ هذا

  • لا تلصق هذا الرمز في المحادثة أو البريد أو أي تذكرة. هذا النموذج يحفظه في ملف محلي فقط.
  • الرمز المطلوب هو رمز بصلاحية الحساب (Account-scoped) يسمح بإدارة رموز/مفاتيح الحساب:
  • Cloudflare → My Profile → API Tokens → Create Token → Custom token، مع الصلاحيتين: Account → Account API Tokens → Edit و User → API Tokens → Edit.
  • هذا الرمز محدود ويُستخدم لإبطال مفتاح R2 القديم المكشوف وتدوير رمز الإنتاج، ثم يمكنك حذفه بالكامل.

معرّف الحساب: 47f4042417b8f04821fd5545fdd3b83f

1) أدخل الرمز واحفظه محلياً

عند الحفظ اختر المجلد المشروع: fahimni/.secrets/ والاسم cf-account-token. الملف يجب أن يبقى بصلاحية 600 ويُحذف بعد الاستخدام.

2) ما الذي سيحدث بعد ذلك (ينفّذه الوكيل على الخادم)

  1. إبطال مفتاح R2 القديم المكشوف (الذي يبدأ بـ adfc4dad) والتأكد من رفضه.
  2. إنشاء رمز إنتاج جديد بنفس صلاحيات النطاق الدنيا وتطبيقه عبر rotate-cloudflare-token.sh.
  3. حذف رمز الإنتاج القديم، والتأكد من أن البدائل تعمل، مع الحفاظ على مفتاح التعافي fahimni-age.key.
  4. مراجعة السجلات وسلامة النسخ الاحتياطي، ثم حذف ملف الرمز.

لا يُطبع أي سرّ في السجلات أو المحادثة في أي خطوة.

بديل بلا رمز حسابي (بضع نقرات في اللوحة)

  1. Cloudflare → R2 → Manage R2 API Tokens → احذف المفتاح الذي يبدأ adfc4dad (دون 1ceeee).
  2. أنشئ رمزاً جديداً بصلاحيات النطاق نفسها (SSL/DNS Edit + Zone Read على fahimni.me) والصقه في هذا النموذج.
  3. بعد أن يؤكّد الوكيل التطبيق، احذف الرمز القديم من My Profile → API Tokens.
