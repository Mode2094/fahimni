## (2) التصميم — إعادة استخدام لا استبدال

- **الخطط/الميزات/الحدود:** `subscription_plans` + `plan_features` كما هي. لا شيء «يُفعَّل» يدويًا: تغيير الخطة يغيّر ما يستنبطه `PlanEngine` مباشرة (`PlanEngine::bumpVersion()`).
- **الوصول:** يبقى محكومًا بـ `TenantSubscription` (النظام القديم) + `admin_ends_at` (منحة المشرف الإضافية) عبر `SubscriptionState`. هذا يجعل المنحة تدوم حتى لو وصل Webhook قديم من Freemius.
- **الدفع:** النظام المالي القائم `payments`/`transactions`/`invoices` لم يُعدَّل، ولم يُشغَّل أي Gateway.
- **السجل:** جدول إضافي `manual_subscription_operations` — لا يُعيد كتابة الأرشيف المالي أبدًا.

### سياسة التواريخ
- `activate` على محاولة/منتهٍ: يبدأ الآن.
- `renew`/`extend`: تحافظ على الأيام المتبقية = `max(prevEnd, now) + duration`.
- `upgrade`/`downgrade`/`plan_change`: تبقى النهاية كما هي إن لم تُحدَّد مدة.
- `starts_at`/`ends_at` الصريحة تتجاوز الحساب.

### الدفعات والمنح
- عملية مدفوعة → `Payment` (manual/completed) + قيد `Transaction` (in) + `Invoice` (paid)، وكلها مرتبطة بالاشتراك.
- `free_grant` (أو مبلغ ≤ 0) → **لا** Payment/Transaction/Invoice إطلاقًا.
