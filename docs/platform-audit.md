# المسح الشامل لمنصة LMS التعليمية

> تاريخ المسح: 2026-08-01 | النسخة: شاملة لكل مكونات المنصة

---

## 1. نظرة عامة على المنصة

منصة تعليمية متكاملة (SaaS) مبنية على **Laravel 13 (PHP 8.3) + Next.js 16 (React 19)** بتصميم ثنائي اللغة (عربي RTL أولاً + إنجليزي)، مع قاعدة بيانات **PostgreSQL** وذاكرة تخزين مؤقتة **Redis** وطوابير **Horizon**.

المنصة تخدم **معلمين مستقلين** في نظام متعدد المستأجرين:

| النوع | الوصف | الجمهور |
|---|---|---|
| `tutor` (معلم) | معلم مستقل يبيع كورساته وطلابه | المعلمون |

كل مستأجر يحصل على: موقع عام خاص (مع إمكانية دومين مخصص)، اشتراك بخطة (تجربة مجانية)، إعدادات علامة تجارية، ولوحة تحكم للمعلم.

## 2. البنية التقنية

### الخلفية (Backend — Laravel 13)
- **المصادقة**: Sanctum bearer tokens + 2FA (TOTP) + كابتشا رياضية + حدود معدل (3 تسجيلات/دقيقة، 5 دخول/دقيقة)
- **متعدد المستأجرين**: Header `X-Tenant-Id` يمر عبر `TenantMiddleware` — كل الجداول الأساسية تحمل `tenant_id`
- **الصلاحيات**: Spatie Laravel Permission (أدوار + صلاحيات، guard web)
- **المعرفات**: UUID v7 لجميع المفاتيح الأساسية (HasUuid trait)
- **الطوابق**: Horizon (Redis) + جدولة يومية (إحصائيات، نسخ احتياطي 02:00 مع الاحتفاظ 7 نسخ)
- **المراقبة**: Sentry + ErrorLogger + سجلات التدقيق (AuditLog)
- **المعارض الخارجية**: 22 بوابة تكامل (فيديو، ملفات، اجتماعات، مراسلة، أتمتة) عبر معمارية Drivers

### الواجهة (Frontend — Next.js 16 App Router)
- **130 صفحة** + 12 تخطيط (Layout) + 25 مكوّن + 4 مخازن Zustand + 4 وحدات خدمات API
- البنية: `@/*` → `src/*`، Tailwind 4، lucide-react، recharts، qrcode، sonner
- رابط API: `NEXT_PUBLIC_API_URL` (افتراضياً `http://localhost:8080/api/v1`)
- i18n: عربي أولاً (RTL) مع تبديل عربي/إنجليزي

## 4. الوحدات الوظيفية الكاملة

### 4.1 نظام التعلم الإلكتروني (LMS)
| الوحدة | التفاصيل |
|---|---|
| **الكورسات** | عنوان، وصف، مستوى، فئة، وسوم، سعر، حد أقصى للطلاب، معايير إكمال، شهادة مفعلة، تعليم تدريجي (Drip)، متطلبات سابقة، تصميم شهادة، نشر/إلغاء نشر، بحث داخلي |
| **الأقسام والدروس** | أقسام مرتّبة، دروس (مدة، معاينة مجانية، نوع)، إعادة ترتيب |
| **محتوى الدرس** | محتوى متعدد الأنواع متعدد الأشكال: فيديو (محمي)، نص، ملف (محمي)، جلسة مباشرة — مع `is_required` |
| **التسجيل والتقدم** | تسجيل طلاب، نسبة إكمال تلقائية، تتبع وقت المشاهدة، إتمام الدروس، إصدار شهادة تلقائي عند الإكمال |
| **بنك الأسئلة** | 8 أنواع: اختيار من متعدد، صح/خطأ، سحب وإفلات، مطابقة، ترتيب، ملء الفراغ، كتابة، رفع ملف — مع لوحة رموز رياضيات/كيمياء (LaTeX) ورفع صور |
| **الامتحانات** | مدة، درجة نجاح، عدد محاولات، خلط الأسئلة/الخيارات، أقسام امتحان، تصحيح تلقائي، إظهار/إخفاء النتائج، نشر |
| **المحاولات** | محاولات مرقمة، تصحيح فوري، نسبة ونجاح، وقت مستغرق، مراجعة الإجابات |
| **الواجبات** | نقاط، تأجيل/رفض متأخر، رفع ملفات، تسليم الطالب، تصحيح مع ملاحظات، تعليقات على التسليمات |
| **الشهادات** | رقم شهادة فريد، قوالب، لون/توقيع مخصص، رمز QR → صفحة تحقق عامة `/verify/{number}` |
| **البث المباشر** | جلسات (مزود: custom/meeting)، تسجيل، حد مشاركين، بدء/إنهاء/إلغاء، أحداث Zapier |
| **الدروس المجدولة** | لمرة واحدة أو متكررة أسبوعياً حتى تاريخ، رابط اجتماع، إكمال/إلغاء |
| **بطاقات التسجيل** | دفعات بطاقات برموز فريدة + QR، استيراد Excel، قالب استيراد، استرداد، إلغاء، حالة دُفعة |
| **حماية المحتوى** | فيديو: توقيع HMAC + مدة صلاحية + علامة مائية + منع التنزيل/التصوير (player مخصص) — ملفات: تذاكر موقعة قصيرة الأمد + تحقق من التسجيل + سياسة تنزيل |

### 4.2 المجتمع (Community)
- **المجموعات**: رؤية، سياسة انضمام، أعضاء (عضو/مشرف)، انضمام/مغادرة
- **الموضوعات**: نقاش/سؤال/إعلان، وسوم، تثبيت، فتح/إغلاق/إخفاء، إعجابات
- **التعليقات**: ردود، **إجابة مقبولة** (Q&A)، إعجابات متعددة الأشكال

### 4.3 الألعاب والتحفيز (Gamification)
- **نقاط**: سجل نقاط (تسجيل دخول يومي، إكمال درس، اجتياز امتحان، إتمام كورس...)
- **10 إنجازات** ثنائية اللغة (أول كورس، أول درس، 10/50 درساً، إتمام كورس، 3 كورسات، اجتياز امتحان، 5 امتحانات، درجة كاملة، 500 نقطة)
- **لوحة صدارة** + نشاطات + مفضلات + ملف شخصي غني (شارات/كؤوس/عملات)
- التقييم عبر Observers (تسجيل، محاولة، تقدم درس)

### 4.4 الاشتراكات والمدفوعات
- **3 خطط** بالريال: Starter 49.99، Professional 99.99، Enterprise 199.99 (شهرياً) — تجربة 14-30 يوماً — 17-19 ميزة لكل خطة (حد طلاب، كورسات، تخزين، بث مباشر، مجتمع، مواعيد، خدمات مدفوعة، معلمون متعددون، API، White Label...)
- **تطبيق الميزات**: `CheckFeature` middleware + `FeatureService` (قيود رقمية/غير محدودة)
- **البوابات**: PayTabs، PayPal، بوابة تجريبية (Fake) + اختبار اتصال
- **الكوبونات**: نسبة/مبلغ ثابت، تفعيل/تعطيل
- **الفواتير والحركات**: فواتير لكل اشتراك + سجل حركات مالية
- **إدارة المشرف**: تغيير خطة/حالة/تمديد، إدارة مدفوعات وطلاب

### 4.5 الإشعارات والتواصل
- **قنوات 5**: داخل التطبيق، بريد، push (FCM + APNs)، SMS (Twilio/log)، WhatsApp (Meta Cloud/log)
- **تفضيلات القنوات** لكل مستخدم
- **الإعلانات**: جماهير مستهدفة + جدولة + قنوات متعددة
- **الدردشة**: محادثات مباشرة، قراءة/غير مقروءة، أذونات الاقتران

### 4.6 التكاملات (Integrations) — 22 مزوداً

### 4.7 مواقع المعلمين العامة (t/[slug])
- **منشئ مواقع**: 4 قوالب تصميم (حديث داكن/مشرق/فاخر/أكاديمي) + **11 نوع كتلة** (بطولة، نص، صورة، فيديو، إحصائيات، عني، كورسات، بطاقة تسجيل، آراء، أسئلة شائعة، دعوة) + معاينة أجهزة
- **مدير الدومينات**: بحث توفر (Namecheap/GoDaddy/Cloudflare/Hostinger)، ربط، تحقق DNS
- **الخدمات المدفوعة**: استشارات/جلسات (سعر/مدة) + **حجز مواعيد** (أوقات متاحة أسبوعياً + فتحات حرة + تعارضات)
- **المدونة**: مقالات عامة + خاصة
- **فريق متعدد المعلمين**: دعوات بالبريد (token)، أدوار، حدود حسب الخطة

### 4.8 الإدارة المركزية (Admin)
- لوحة إحصائيات شاملة + إيرادات
- إدارة الاشتراكات (تغيير خطة/تمديد/تعليق)
- منشئ خطط (أنواع ميزات: منطقية/رقمية/اختيار/مخصص)
- كوبونات، مدفوعات، فواتير، بطاقات
- **تذاكر الدعم** (أولوية + إسناد + ردود)
- **سجلات الأخطاء** + **سجلات التدقيق** + **النسخ الاحتياطي** (pg_dump)
- إعدادات المنصة (اسم، عملة، تحويل، كابتشا، 2FA، بوابات)

### 4.9 الأمان
- 2FA (TOTP مع رمز استرداد)
- كابتشا رياضية
- حدود معدل
- **التحكم بالأجهزة**: حد أجهزة لكل طالب، تتبع نشاط، إعادة تعيين، سياسة عامة
- حماية فيديو (توقيع HMAC + مدة + علامة مائية + منع PIP/تنزيل)
- حماية ملفات (تذاكر موقعة + تحقق تسجيل)
- سجلات تدقيق لكل العمليات الحساسة

### 4.10 التحليلات والتقارير
- منصة (DashboardController) + يومية (DailyStats)
- **معلم**: نظرة عامة، إيرادات، كورسات، امتحانات، زيارات + **تصدير PDF (DomPDF) وExcel (PhpSpreadsheet)**

## 7. ملاحظات فنية للفريق

1. `src/proxy.ts` غير مفعّل كـ middleware (يحتاج إعادة تسمية/استيراد) — خاص بدومينات المعلمين.
2. إعداد `captcha_enabled` في لوحة الإدارة يؤثر على كل صفحات الدخول (يُنصح بإيقافه في بيئة التطوير).
3. الأبجدية العربية RTL معادلة: `useLocale` يضبط `dir` و `lang` تلقائياً.
