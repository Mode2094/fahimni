# قائمة التنفيذ

## الفحص
- [x] فصل العمل عن التعديلات المحلية غير المرتبطة.
- [x] التأكد من استجابة الموقع وفحص الصحة الإنتاجي.
- [x] تحديد فرع RC الحالي ووجود CI جارٍ وغياب Deploy SHA موثوق.
- [x] مراجعة التنقل واللوحات ومسارات التحرير والإعدادات الحالية.

## التنفيذ والتحقق
- [x] تنقل الطالب/المعلم: وجهات يومية، «المزيد»، رسائل المعلم، البحث والأقسام القابلة للطي؛ اختبارات التنقل والشارات (18 ناجحة).
- [x] فحص لوحة مفاتيح/قارئ شاشة لقائمة الهاتف وإغلاقها بمفتاح Escape.
- [x] مهام المعلم المجمعة من بيانات حقيقية: واجبات، اختبارات، حجوزات، وإشعارات؛ مع نطاق المستأجر والمالك/المعلم واختبارات الدقة والصلاحية.
- [ ] فصل خطأ تحميل تعلمي عن حالة الفراغ وتحسين بدء التعلم.
- [ ] تنظيم خطوات إنشاء/تعديل الكورس والحفاظ على المسودات.
- [ ] تجميع إعدادات المعلم مع حفظ كل الخيارات الحالية.
- [ ] حوارات تأكيد/إدخال ورسائل خطأ عربية وإنجليزية.
- [ ] اختبارات RTL والوصولية والهاتف ولقطات المتصفح.
- [ ] مراجعة نهائية للـdiff ثم CI وPR.

## النشر
- [ ] لا يُنفذ إلا بعد اكتمال الفحوص، وخلو CI، وتوفر مسار نشر مصرح وآمن.
